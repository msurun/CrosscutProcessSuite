# Provenance log

Every method implemented in this repository is listed here with its public source before the code is merged.
All code, data and parameters in this repository are original or taken from the public sources cited below.
All datasets are synthetic, generated by the simulators in `sim/`.

Citations are given from memory and must be verified against the originals before the first release.

1. Add a row (source, date, author of the implementation) before implementing a method.
