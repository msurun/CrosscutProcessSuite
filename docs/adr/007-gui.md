# ADR 007: Web GUI on a local FastAPI backend, React + TypeScript frontend

Status: proposed (2026-10-10), to be confirmed when stage 1 starts

- The engineer's Studio and the operator UI are web applications served locally (on-premises, no cloud needed).
- Backend: FastAPI (Python) exposing a REST and WebSocket API generated from typed models; OpenAPI is the contract.
- Frontend: React + TypeScript; time-series viewer on uPlot; forms generated from the JSON Schemas where possible.
- Configuration is data (YAML/JSON validated by the schemas); the GUI edits it and never requires scripting.
- Stage order: Data Studio and trend viewer, then loop monitoring, then wizards, then the operator UI.
- Testing: component tests (Vitest) and end-to-end tests (Playwright) in CI; the simulator and OPC UA test server
  provide data for demos and tests.
- Rejected for the product: Streamlit/Dash (fast, but limited control over layout, state and operator-grade UX);
  they remain acceptable for throw-away prototypes.
