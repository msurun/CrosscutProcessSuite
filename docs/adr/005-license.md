# ADR 005: Apache-2.0

Status: accepted (2026-10-10)

The repository is licensed under Apache-2.0 (patent grant, permissive, widely accepted in industry). The repository is
private for now; the decision to publish specific libraries is separate. Dependencies must be compatible with a
possible closed-source product: avoid GPL/AGPL, check MPL and LGPL usage before adding a dependency.
